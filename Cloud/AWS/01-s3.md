# S3 — Simple Storage Service

**Opis**
S3 to nieskończony "chmurny dysk": wrzucasz pliki (obiekty) do bucketów i pobierasz je po nazwie. Brak serwerów, brak dysków, brak filesystemu — po prostu `bucket/key → bajty`.

**Kluczowe koncepty**
- **Bucket** — nazwany kontener (nazwa globalnie unikalna w AWS); do niego wrzucasz obiekty.
- **Object** — plik + metadane; adresowany **kluczem** (path w bucket).
- **Dostęp** — domyślnie prywatny; otwierasz przez bucket policy, ACL albo presigned URL (czasowy link).
- **Versioning** — nadpisanie obiektu nie kasuje starej wersji, można cofnąć.
- **Lifecycle rules** — np. po 30 dniach przenoś do Glacier, po roku usuń.

**Key points**
- Obiekty leżą w **bucketach**; każdy obiekt ma klucz (swój "path").
- **Versioning**: nadpisanie obiektu zachowuje starą wersję — odzyskasz usunięte pliki lub cofniesz zmianę.
- **Lifecycle rules**: automatyczne przenoszenie starych danych na tańsze storage (np. Glacier) lub ich usuwanie.
- Ogromna trwałość (11 dziewiątek) — AWS replikuje dane za kulisami.

**Example (AWS CLI)**
```bash
# podstawy
aws s3 cp report.csv s3://my-bucket/data/report.csv        # upload
aws s3 cp s3://my-bucket/data/report.csv .                 # download
aws s3 ls s3://my-bucket/data/
aws s3 rm s3://my-bucket/data/old.csv                      # usunięcie

# cały katalog rekurencyjnie
aws s3 cp ./build/ s3://my-bucket/releases/v1/ --recursive

# presigned URL — czasowy link (np. na 1h) do prywatnego obiektu
aws s3 presign s3://my-bucket/data/report.csv --expires-in 3600
```

```bash
# versioning: włącz, pokaż wersje, przywróć starą
aws s3api put-bucket-versioning --bucket my-bucket \
  --versioning-configuration Status=Enabled

aws s3api list-object-versions --bucket my-bucket --prefix data/report.csv \
  --query 'Version[?IsLatest == `false`].[Key,VersionId,LastModified]'

aws s3api copy-object --bucket my-bucket --key data/report.csv \
  --copy-source 'my-bucket/data/report.csv?versionId=abc123' \
  --copy-source-if-match 'etag'
```

**Pełny flow** — od zera do działającego bucketa z polityką:
```bash
# 1. utwórz bucket (nazwa globalnie unikalna)
aws s3 mb s3://my-app-prod-data

# 2. włącz versioning (bezpieczeństwo przed pomyłką/usunięciem)
aws s3api put-bucket-versioning --bucket my-app-prod-data \
  --versioning-configuration Status=Enabled

# 3. wrzuć dane
aws s3 cp ./reports/ s3://my-app-prod-data/reports/ --recursive

# 4. ustaw lifecycle: po 30 dniach -> Glacier, po 365 -> usuń
aws s3api put-bucket-lifecycle-configuration --bucket my-app-prod-data \
  --lifecycle-configuration '{"Rules":[{"ID":"archive","Status":"Enabled",
    "Prefix":"reports/","Transitions":[{"Days":30,"StorageClass":"GLACIER"}],
    "ExpirationInDays":365}]}'

# 5. daj komuś czasowy dostęp bez hasła (presigned URL)
aws s3 presign s3://my-app-prod-data/reports/2026-09.csv --expires-in 3600
# -> https://my-app-prod-data.s3.amazonaws.com/reports/2026-09.csv?X-Amz-...

# 6. zweryfikuj stan
aws s3api get-bucket-versioning --bucket my-app-prod-data
aws s3api get-bucket-lifecycle-configuration --bucket my-app-prod-data
```
